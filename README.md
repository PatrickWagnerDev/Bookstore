# Bookstore

Bookstore is a small web app and bootcamp exam project for practicing how to read, modify, and manage data using JSON and JavaScript objects.

## Features

* Read JSON data – Load and display book data from JSON
* Modify data – Update and manage existing book data
* Like books – Like and unlike books with a functional like system
* Add comments – Write and display comments for books
* Local Storage – Save modified data in Local Storage
* Persistent data – Retrieve saved data from Local Storage after reloading the page

## Technologies

* HTML
* CSS
* JavaScript
